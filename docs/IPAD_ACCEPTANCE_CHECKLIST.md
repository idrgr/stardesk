# StarDesk iPad 实机验收清单

> **说明**：下列项目需在**真实 iPad + Safari**（或已添加到主屏幕的 Web App）上由用户自行勾选。  
> Playwright WebKit / viewport 自动化通过 **不能** 等同于本清单全部完成。

## 环境与访问

- [ ] 在 iPad Safari 中通过 **HTTPS** 或可信局域网地址打开 StarDesk（非仅 `localhost`）
- [ ] 页面可正常加载，无证书/混合内容错误
- [ ] 深色与浅色主题切换正常

## 安装与 PWA

- [ ] Safari → 分享 → **添加到主屏幕**
- [ ] 主屏幕图标清晰、名称正确（StarDesk / 星枢）
- [ ] 从主屏幕启动进入 **standalone**（无 Safari 地址栏）
- [ ] standalone 下顶栏/内容未被刘海或 Home 指示条遮挡（Safe Area）

## 横屏 / 竖屏

- [ ] **竖屏**：侧栏以抽屉呈现，主导航可用
- [ ] **横屏（≥1024px 宽）**：侧栏固定显示，内容区宽度合理
- [ ] 各主要页面无整页横向滚动
- [ ] 弹窗、抽屉不超出屏幕

## 日常操作

- [ ] 新增任务、编辑、完成
- [ ] 设为今日重点（无需 hover 才看到按钮）
- [ ] 中文输入法输入任务标题与搜索（选词过程中不误提交）
- [ ] 专注：开始 → 结束 → **转为领域记录**（不重复生成活动）
- [ ] Markdown 笔记新建与保存
- [ ] 周复盘编辑长文本
- [ ] 全局搜索（外接键盘 **⌘/Ctrl + K**）

## 数据与备份

- [ ] 导出 JSON：提示为「已发起下载 / 备份文件已生成」，不声称固定目录
- [ ] 从「文件」选择备份并恢复（预览 → 确认）
- [ ] 损坏备份被拒绝，原数据不变
- [ ] 明确理解：数据在 Web App 本地存储，**不会**自动 iCloud 备份

## 可靠性与更新

- [ ] 切到后台再返回，专注/表单状态合理
- [ ] 断网后从主屏幕再次打开（曾成功加载过）仍可进入应用 shell
- [ ] 有新版本时出现「重新加载后更新」提示，可稍后或手动刷新
- [ ] 两个 Safari 标签页同时打开时，完整恢复后另一页出现数据失效提示

## 外接键盘与无障碍

- [ ] Magic Keyboard：**⌘ + K**、Esc 关闭弹窗、Tab 焦点顺序合理
- [ ] 主要按钮易于点按（约 44pt 触控区域）
- [ ] 系统「减少动态效果」开启时界面仍可用
